สลับ Profile อัตโนมัติ

ตรวจจับการเปลี่ยนจอแล้วคืนค่า layout ที่ตรงกับการต่อจอชุดนั้นให้ทันที

  • จับ WM_DISPLAYCHANGE พร้อมหน่วงเวลาให้ระบบนิ่งก่อนตัดสินใจ
  • ถ้าไม่มี profile ตรงเป๊ะ จะหา profile ที่ใกล้เคียงที่สุดจากชุดจอเดิม
  • กู้ทันทีเมื่อ Explorer รีสตาร์ท — สาเหตุอันดับต้นๆ ที่ไอคอนเละ ซึ่งเครื่องมืออื่นไม่จับ
  • บันทึกอัตโนมัติก่อนเข้า Sleep และก่อน Shutdown
⏱

ย้อนเวลาได้ทุกเมื่อ

เก็บประวัติ snapshot ย้อนหลัง 30 ครั้ง กดย้อนกลับไปจุดไหนก็ได้ ลบทีละรายการหรือล้างทั้งหมดได้

  • ดูตัวอย่างก่อนคืนค่าจริงเสมอ ไม่มีการเปลี่ยนแปลงแบบไม่ทันตั้งตัว
  • แต่ละ snapshot เก็บ ภาพหน้าจอจริง แยกตามจอไว้ให้ดูย้อนหลัง
  • ลบ snapshot ในไทม์ไลน์ทีละรายการ หรือล้างเฉพาะรูปทั้งหมดเพื่อคืนพื้นที่ดิสก์ — อย่างหลังตำแหน่งไอคอนยังอยู่ครบ คืนค่าได้เหมือนเดิม

Mini-map ดูก่อนคืนค่า

แผนที่ย่อส่วนตามสัดส่วนจริง แสดงว่าไอคอนไหนจะย้ายไปไหนก่อนกดยืนยัน

  • แยกสีตามประเภทไฟล์ — โฟลเดอร์ ทางลัด เอกสาร รูปภาพ และอื่นๆ
  • เส้นโยงบอกทิศทางการย้ายของแต่ละไอคอน
  • มี กรอบเส้นประ บอกโซนที่ไอคอนใหม่จะไปอยู่

  • เสียบจอกลับเมื่อไหร่ ไอคอนกลับไปที่เดิมเอง
  • เลือกได้ว่าไอคอนใหม่ที่ยังไม่เคยบันทึกจะไปกองมุมไหน จอไหน

เบาจนลืมว่าเปิดอยู่

ทำงานเงียบๆ ใน System Tray แบบ event-driven ล้วน ไม่มี polling loop

  • ใช้แรม 20–40 MB ตอนย่อลง tray
  • CPU 0% ขณะไม่มีอะไรเปลี่ยนแปลง
  • ไฟล์เดียว ไม่ต้องติดตั้ง ไม่ต้องลง runtime เพิ่ม

  • แปลครบทั้งหน้าต่าง รวมถึงเมนู tray
  • Title bar เปลี่ยนตามธีมด้วย ไม่ใช่แค่พื้นที่ในหน้าต่าง

ย้ายเครื่องได้

Export / Import profile เป็นไฟล์ JSON อ่านออกด้วยตาเปล่า

  • สำรองไว้ หรือส่งให้เครื่องอื่นใช้ layout เดียวกัน
  • ซิงก์อัตโนมัติ ผ่านโฟลเดอร์ OneDrive / Dropbox / เน็ตเวิร์กไดรฟ์
  • ข้อมูลทั้งหมดอยู่ในเครื่องคุณ ไม่มีเซิร์ฟเวอร์ ไม่ต้องสมัครบัญชี
📌

โซนอัตโนมัติและการปักหมุด

ไม่ใช่แค่คืนตำแหน่ง แต่จัดระเบียบให้ด้วย

  • ตั้งโซนมีชื่อพร้อมกฎ — ไฟล์ประเภทไหนหรือชื่อขึ้นต้นอะไร ไปโซนไหน
  • ไอคอนใหม่ถูกจัดเข้าโซนที่ตรงกฎเอง ไม่ใช่กองรวมมุมเดียว
  • ปักหมุดไอคอนให้อยู่ที่เดิมเสมอ ชนะทุกการคืนค่า
  • ลากกรอบบนแผนผังเพื่อสร้างโซนใหม่ได้ทันที ไม่ต้องกรอกพิกัด
🧠

เรียนรู้จากพฤติกรรมคุณ

ระบบดูประวัติแล้วหาไอคอนที่คุณต้องลากกลับที่เดิมซ้ำๆ แล้วเสนอให้ปักหมุด

  • สัญญาณคือ "เร่ร่อนแต่กลับบ้านเสมอ" ไม่ใช่ "ไม่เคยขยับ" เพราะตัวที่ไม่เคยขยับไม่ต้องช่วยอะไร
  • บอกด้วยว่ามั่นใจแค่ไหน กลับมาที่เดิมกี่ครั้งจากทั้งหมดกี่ครั้ง
📊

รู้ว่าเดสก์ท็อปรกแค่ไหน

ใช้ประวัติที่เก็บอยู่แล้วมาตอบคำถามที่ไม่มีเครื่องมือไหนตอบได้

  • จำนวนไอคอนเพิ่มหรือลดกี่ตัวใน 30 วัน พร้อมกราฟย้อนหลัง
  • ไฟล์ที่ไม่ได้แก้ไขเกิน 90 วัน เรียงจากค้างนานที่สุด
  • เปรียบเทียบ snapshot สองอันว่าอะไรเพิ่ม หาย หรือย้าย พร้อมเส้นโยงบนแผนที่
  • ไทม์ไลน์ภาพหน้าจอย้อนหลัง ดูเดสก์ท็อปเปลี่ยนไปตามเวลา
🎬

ปรับตามสถานการณ์

สลับ layout ตามที่คุณอยู่และสิ่งที่คุณกำลังทำ ไม่ใช่แค่ตามจอที่ต่อ

  • ตั้งกฎตามชื่อ Wi-Fi · ช่วงเวลา · โปรแกรมที่เปิดอยู่
  • โหมดนำเสนอ ซ่อนไอคอนทั้งหมดในคลิกเดียว และเข้าเองได้เมื่อต่อโปรเจกเตอร์
  • ใช้คำสั่งของ shell เอง ไม่ย้ายไอคอน จึงไม่มีทางทำ layout หาย
🎚

ง่ายหรือลึก เลือกได้

เปิดมาเป็นโหมดใช้งานง่าย เห็นแค่สิ่งที่ต้องใช้จริง กดสวิตช์เดียวเปิดเครื่องมือทั้งหมด

  • โหมดง่าย: บันทึก คืนค่า และประวัติ เท่านั้น
  • โหมดขั้นสูง: โซน หมุด ไทม์ไลน์ วิเคราะห์ กฎอัตโนมัติ และซิงก์
📖

  • 10 หัวข้อ ครอบคลุมทุกฟีเจอร์ ตั้งแต่เริ่มต้น 3 ขั้นตอนจนถึงการแก้ปัญหาและช่องทางแจ้งปัญหา
  • สารบัญกดกระโดดไปหัวข้อที่ต้องการได้เลย
  • ภาษาไทยและอังกฤษ เปลี่ยนพร้อมกับทั้งแอป

ข้อมูลทางเทคนิค

สำหรับคนที่อยากรู้ว่าข้างในทำงานยังไง

ระบบที่รองรับWindows 10 (1703 ขึ้นไป) และ Windows 11 · 64-bit
สิ่งที่ต้องมีไม่มี — ไฟล์หลักรวมทุกอย่างไว้ในตัวแล้ว (ไฟล์ทางเลือกขนาดเล็กต้องมี .NET 10 Desktop Runtime)
ขนาดไฟล์ไฟล์เดียว 66 MB รวม runtime · หรือแบบเล็ก 1.9 MB สำหรับเครื่องที่มี .NET 10 อยู่แล้ว
หน่วยความจำ20–40 MB ขณะย่อลง System Tray
การใช้ CPU0% ขณะ idle — เป็น event-driven ไม่มี polling
วิธีอ่าน/เขียนตำแหน่งShell COM IFolderView ซึ่งเป็น API สาธารณะของ Windows ไม่ใช้การ inject เข้า explorer.exe
การระบุตัวจอEDID (รหัสผู้ผลิต + รหัสรุ่น) จึงไม่สับสนเมื่อสลับพอร์ต
DPIPer-Monitor-V2 aware ทำงานในพิกัดเดียวกับ explorer.exe จึงไม่เพี้ยนเมื่อ scaling ต่างกันแต่ละจอ
สิทธิ์ที่ใช้ผู้ใช้ทั่วไป — ห้ามรันแบบ Run as administrator เพราะ UAC จะบล็อกการเชื่อมต่อกับ explorer.exe
ที่เก็บข้อมูล%LOCALAPPDATA%\ReDesk\ เป็นไฟล์ JSON และ JPEG ทั้งหมดอยู่ในเครื่อง
ข้อควรทราบต้องปิด Auto arrange icons ของ Windows ก่อนใช้งาน ตัวโปรแกรมจะแจ้งเตือนให้

คำถามที่พบบ่อย

ทำไมต้องปิด "Auto arrange icons" ของ Windows

ถ้าเปิดออปชันนี้ไว้ Windows จะบังคับเรียงไอคอนใหม่ตลอดเวลา และทิ้งตำแหน่งที่โปรแกรมไหนก็ตามเขียนลงไป ไม่ใช่แค่ ReDesk — ทำให้การคืนค่าไม่มีผล ตัวโปรแกรมจะตรวจให้อัตโนมัติและเตือนถ้ายังเปิดอยู่ วิธีปิด: คลิกขวาบนเดสก์ท็อป → View → เอาติ๊ก "Auto arrange icons" ออก

ทำไมห้ามรันแบบ Run as administrator

ReDesk ต้องคุยกับ explorer.exe ผ่าน COM ซึ่ง explorer รันที่ระดับสิทธิ์ปานกลาง UAC ห้ามโปรเซสสิทธิ์สูงกว่าเชื่อมต่อกับ COM object ของโปรเซสสิทธิ์ต่ำกว่า การรันแบบผู้ดูแลระบบจึงทำให้โปรแกรม ใช้งานไม่ได้ ไม่ใช่ทำงานดีขึ้น

ปลอดภัยไหม มีการส่งข้อมูลออกนอกเครื่องหรือเปล่า

ไม่มีการเชื่อมต่อเครือข่ายใดๆ ข้อมูลทั้งหมด (ตำแหน่งไอคอน ภาพหน้าจอ การตั้งค่า) เก็บอยู่ใน %LOCALAPPDATA%\ReDesk\ เป็นไฟล์ JSON และ JPEG ที่เปิดอ่านตรวจสอบเองได้ และ ReDesk ใช้ API สาธารณะของ Windows ไม่ได้ inject โค้ดเข้าโปรเซสอื่น

ภาพหน้าจอที่เก็บไว้จะติดหน้าต่างที่เปิดค้างไว้ไหม

ไม่ติด ReDesk สั่งให้หน้าต่างเดสก์ท็อปวาดตัวเองลงบัฟเฟอร์นอกจอโดยตรง จึงได้ภาพวอลเปเปอร์กับไอคอนล้วนๆ เสมอ ต่อให้ตอนนั้นเปิดโปรแกรมเต็มจอค้างไว้ก็ตาม และไม่มีการกระพริบหรือย่อหน้าต่างใดๆ

ต่อ 3 จอขึ้นไปได้ไหม

ได้ ไม่จำกัดจำนวนจอ ทุกจอจะถูกบันทึกตำแหน่งและเก็บภาพหน้าจอแยกกัน หน้าต่างดูภาพจะแยกเป็นแท็บต่อจอเพื่อให้ดูได้ชัดเจน

ถ้าลบไฟล์บนเดสก์ท็อปไปแล้ว snapshot เก่าจะพังไหม

ไม่พัง ReDesk อ้างอิงไอคอนด้วยเส้นทางไฟล์จริง ไม่ใช่ลำดับที่ ไฟล์ที่ไม่มีอยู่แล้วจะถูกข้ามไปเงียบๆ และรายงานจำนวนให้ทราบ ส่วนไฟล์ใหม่ที่ไม่มีใน snapshot จะถูกจัดไปไว้ในโซนที่คุณกำหนด ไม่ทับของเดิม

🐞 แจ้งปัญหา บอกอาการที่เจอ ถ้าเปิด ReDesk อยู่แล้ว กดปุ่ม “แจ้งปัญหาที่พบ” ในแท็บวิธีใช้งาน จะกรอกข้อมูลระบบให้อัตโนมัติ 💡 เสนอไอเดีย อยากให้ ReDesk ทำอะไรได้อีก เล่าสถานการณ์ที่เจอมาได้เลย 📋 ดูรายการที่แจ้งไว้แล้ว เช็กก่อนว่ามีคนแจ้งเรื่องเดียวกันหรือยัง และติดตามได้ว่าแก้ถึงไหนแล้ว
